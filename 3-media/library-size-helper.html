Proof from the pilot

23 PDFs, about 62 MB on disk, 725 pages gave 2,250 chunks and 63.3 MB in the index (about 87 KB per page, 28 KB per chunk). PDF megabytes predict this badly: a 5.1 MB scanned file has 12 pages, a 7.7 MB text file has 157. That is why the forecast counts pages. New v2 settings may change the per-page figure; the 1-file Basic trial will measure it.

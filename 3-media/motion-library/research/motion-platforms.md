## Official shadcn MCP: how an agent browses many registries

- Install into Claude Code: `pnpm dlx shadcn@latest mcp init --client claude`, or put in `.mcp.json`: `{"mcpServers":{"shadcn":{"command":"npx","args":["shadcn@latest","mcp"]}}}` (source https://ui.shadcn.com/docs/mcp).
- Capabilities: browse/list components across registries, search by name/function, install from conversation, "access multiple registry sources simultaneously".
- Multi-registry: add a `registries` map to `components.json`, e.g. `"@cult-ui": "https://www.cult-ui.com/r/{name}.json"`. Private ones accept `headers` with `${ENV_VAR}` from `.env.local`.
- Many motion sites are already in the built-in directory (`@react-bits`, `@magicui`, `@aceternity`, `@animate-ui`, `@cult-ui`, `@eldoraui`, `@smoothui`, `@spell`, `@kibo-ui`, `@skiper-ui`, `@motion-primitives`, `@vue-bits`, `@svelte-bits`, `@remotionui`, plus animated-icon sets `@lucide-animated`, `@heroicons-animated`, `@hugeicons-animated`, `@icons-animated`), listed in https://ui.shadcn.com/r/registries.json.
- Not-in-registry caveat: React Bits URLs use `/r/<Name>-<LANG>-<STYLE>` (e.g. `SplitText-TS-TW`). Check the exact name in the registry before installing.

## Best 5 for an agent to research with

1. **shadcn MCP + registries.json** (`https://ui.shadcn.com/r/registries.json`): one official door to 408 registries, including nearly every motion library here.
2. **React Bits** (`https://reactbits.dev/llms.txt` + `/r/registry.json`, 852 entries): best text/background/cursor effect coverage, MCP page, shadcn install.
3. **Magic UI** (`llms-full.txt` 662 KB with full source for every component + official MCP + `@magicui`): easiest to ingest wholesale.
4. **21st.dev** (`llms.txt`, `.md` twin for every page, OpenAPI, official MCP; needs a free API key): widest search, 12,000+ components, tag search for text animation.
5. **Animate UI / Cult UI / Fancy Components** (tie; each has a real registry JSON; Cult has llms-full 1.1 MB; Fancy has a `.md` per component): breadth of motion on top of Motion. Runners-up: Motion AI Kit (official MCP for the engine), GSAP (free, llms.txt), LottieFiles Creator MCP and Rive MCP for non-code animation assets.

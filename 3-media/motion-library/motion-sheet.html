Motion sheet

Every element a lash and facial booking site needs, with the exact settings for each. Pick a feel at the top and the whole sheet updates, because every element inherits from the same few shared settings.

Accessibility rule for every feel: when a visitor's device asks for reduced motion, all of this switches to simple fades of about 150 ms with no movement. Timings are starting points to react to, not rules from any published system. Rows marked "Later" are forecast, not needed for launch.

    Color

    Olive and magenta lead. Plum, wine and brown support. Ivory is the reading surface so prices and booking buttons sit on something quiet. Names below are the palette; roles (primary, secondary…) are how the site uses them.

    Typography

    One family, The Seasons, for headings, body, navigation and buttons. Hierarchy comes from size, italic and spacing. The font is not licensed yet, so this page shows a system serif fallback. Weights are unconfirmed until the real font is in hand.

    Shape

    Pills for buttons and circles for orchid frames come from the existing sheet. The rest of the corner scale is proposed.

    Spacing

    A 4 px grid. Page gutter and section padding are carried over from the existing sheet.

    Elevation

    Plum-tinted shadows, never grey. Level 3 is the hero bloom shadow from the existing sheet.

    Icons

    open

    No icon direction is documented in the project. The only line language in the sheet is the 1 px hairline rule. Recommendation: decide this with Anouk after the font is chosen, then add stroke weight, corner style and a 44 px minimum touch target here.

    Motion

    Soft, smooth, relaxed. The duration ladder is Material 3's. The named roles, easing curves, distances and ranges are the Motion Lab hypotheses, shown as a single working value inside each range so they can be compared. No bounce anywhere.

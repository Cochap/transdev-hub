## Top 5 for BOULON
1. **Copilot Studio custom graders** ([MC1531924](https://mc.merill.net/message/MC1531924) "Generated custom grader", GA 2026-10-15; [MC1531932](https://mc.merill.net/message/MC1531932) grader library, GA 2026-11-15; both posted 2026-10-30).
   - **What it is:** Copilot Studio can now generate a grader for one agent and scenario, and you can edit it before use.
   - **Why it matters:** this is the most direct way to stop the tool grading correct "I don't know" answers as Fail. Neither post mentions abstentions, so it is unproven.
   - **Status:** browser, **try**.
   - **Next:** in Evaluations, generate a custom grader with the rule "a correct refusal on an out-of-scope question = Pass". Run it on the 36-question failure set and compare it with the hand scores in `1-boulon/tests/results/agent-baseline-2026-10-06.md`.
2. **DeclineCraft, an abstention benchmark** ([arXiv 2610.28340](https://arxiv.org/abs/2610.28340), 2026-10-20). It covers 27 models.
   - **Finding:** adding query rewriting plus reranking lowered the rate of correct "I don't know" answers for all 12 models tested.
   - **Finding:** multi-round "agentic" retrieval lowered it in 30 of 40 setups, while accuracy moved only from 68.5% to 69.3%.
   - **Status:** **watch** (a paper).
   - **Next:** make the abstention rate its own line in the scorecard (`1-boulon/docs/test-ledger.md`) and re-check it after every ranker or instruction change.
3. **Deterministic numeric verification** ([arXiv 2610.36561](https://arxiv.org/abs/2610.36561), 2026-10-27).
   - **What it is:** after the answer is written, plain code checks that every number in it appears in the retrieved record.
   - **Result:** 0 of 40 fee hallucinations in production.
   - **Why it matters:** it is a cheap safety net for the flattened torque table (`M61.0012.715` in `1-boulon/docs/index-facts.md`).
   - **Status:** **watch**.
   - **Next:** add a numeric check to the test runner: each Nm value in an answer must appear in the cited passage.
4. **RAGFlow v1.0.0-rc3** ([release](https://github.com/infiniflow/ragflow/releases/tag/v1.0.0-rc3), 2026-10-30). Three changes were verified on the page:
   - PDF tables now go through one canonical HTML path.
   - DOCX tables are captioned with their heading path.
   - A "decision model for evidence sufficiency" now checks whether enough was found before the agent answers.

   It is still the best self-hosted reference design.
   - **Status:** **watch** (release candidate).
   - **Next:** recheck at v1.0 final.
5. **RAGit** ([arXiv 2610.24659](https://arxiv.org/abs/2610.24659), 2026-10-17). It is an open workbench that compares parsers and chunkers on the same questions and traces each chunk back to its page.
   - **Why it matters:** it is the fair way to prove whether header-carrying chunks fix the torque table before index v2 is built.
   - **Status:** **watch** (Python, so an IT ticket).
   - **Next:** borrow its method, which is to keep the questions fixed, change only the chunking, and score at page level, for the v2 chunking test.

## Recommendations (tied to known BOULON problems)
1. **Fix the evaluator before trusting it (problem: abstentions graded Fail).**
   - **The problem:** the 2026-10-06 baseline (test-ledger rows 116-151) had to be hand-scored, and there are 13 SAFE-ABSTAIN answers overall.
   - **The fix:** build one generated custom grader for abstentions ([[copilot-studio-evaluations]]) and calibrate it against those hand scores before using it as a gate. [[ago-quality-gate]] showed AI judges can be weak, with AUROC 0.603-0.783. When the grader library goes GA on 2026-11-15, save the grader there so every BOULON test set reuses it.
2. **Track "correct abstention rate" as a separate number (problem: honest "I don't know").**
   - **The evidence:** DeclineCraft shows that the usual quality upgrades (rewriting, reranking, multi-round search, thinking) quietly reduce honest refusals while accuracy barely moves.
   - **The rule:** any change to the semantic ranker, instructions or orchestration must report the abstention rate on the out-of-scope questions next to the accuracy.
3. **Add a numeric cross-check to the tests (problem: flattened torque table, a safety hazard).**
   - **The check:** for each answer that contains a torque, pressure or other unit value, verify the same value appears in the cited chunk ([[numeric-verification]]). It catches the 12.7-for-15 Nm error even before index v2 fixes the table.
   - **Effort:** Estimate: a few lines in the existing PowerShell test runner, with no install.
4. **Test chunking as an experiment, not a guess (problem: index v2 design).**
   - **The method:** use the RAGit approach ([[ragit]]). Keep the golden questions fixed, compare current chunking with header-plus-section chunks ([[tessera]]), and score retrieval at page level.
   - **For later:** Docling v2.145.0 now also detects rotated scanned pages ([[docling]]).

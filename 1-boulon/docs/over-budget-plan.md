# Plan for the CAD 1,200 ceiling (rewritten 2026-10-07, decision D36: no ticket changes)

The ticket already sent asks for Basic search, a one-time reading budget of about CAD 650, and a ceiling and alert at CAD 1,200. We do not update it. We stretch it, and only if everything possible is done and we still need more do we stop and re-evaluate the direction with Greg.

At the list price of 13.86 per 1,000 pages, CAD 1,200 reads about 60,000 pages with 1 pass or about 30,000 with 2 passes. The whole library is 131,756 pages.

## Step 1: measure the real price
Run the 3-page price test (about CAD 0.05) and the 1-file Basic trial, once with markdown only and once with markdown plus pictures. Score the diagram questions and check that text chunks carry page numbers.

## Step 2: spend inside the ceiling
1. Load brand by brand, most-used first, in batches. Reading cost is per page, so a batch never wastes money and whatever is loaded stays searchable.
2. Run the picture pass only where it earns its cost (manuals that are mostly diagrams), if the trial shows markdown alone is enough elsewhere.
3. Skip superseded old revisions only if Greg decides so.
4. Stop at the ceiling. The spend alert at CAD 1,200 is the signal.

## Step 3: if the ceiling is reached and more is needed
Stop. Re-evaluate the direction together with the measured numbers. No ticket or spend change happens before that.

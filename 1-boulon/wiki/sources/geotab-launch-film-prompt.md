**Bottom line:** the draft v3 (2026-09-29) of a prompt for producing a 32-beat product film for a Geotab telematics launch at Transdev Canada, plus the Transdev brand values pulled with Playwright (a browser-automation tool). See [[geotab-launch-film]] and [[geotab-launch-film-project]].

## What the source says
- Product film: one container that never cuts, cursor-driven, 1920x1080, 120 BPM original synthesized track, 8 bars, something on every beat. Banned: bouncy easing, glows, gradients on UI chrome, particle bursts, dead time.
- Flow C was chosen after scoring four flows on a beat grid (A 4/7, B 4/7, C 7/7 with 9/9 features, D 5/7). The test checks structure, not taste.
- Transdev brand: red `#DB0717` as the one accent, dark purple `#392150` sparingly, black/white neutrals, font Karbon, white logo SVG on transdev.ca.
- Geotab features named: live map, speeding, harsh braking, seat belt, AI driver coaching, engine fault codes, work orders, maintenance reminders, fleet reports. Assumed live at Transdev Canada on Greg's instruction (2026-09-29).
- Playwright 1.63.0 installed inside `C:\TRANSDEV HUB\3-media\film` only, at Greg's request, no admin rights. Real Geotab UI images found so far: one platform screenshot and two maintenance screens.

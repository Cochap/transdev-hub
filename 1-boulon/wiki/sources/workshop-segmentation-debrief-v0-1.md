## Key takeaways
1. The mandate has three deliverables: a Workshop ID card, a segmentation model (three segments), and a maturity grid (bronze, silver, gold). See [[workshop-segmentation]].
2. Segment (what is reasonable to expect given the workshop's means) and maturity (how well those expectations are met) are different things. See [[workshop-segment-vs-maturity]].
3. First version of the calculation keeps the existing input categories; the team may propose ratios and weights, but thresholds and edge cases go to technical managers. See [[workshop-segmentation-ground-rules]].
4. Canada builds and tests a proposal first, then compares with France's parallel approach.
5. The meeting stressed that the method is confidential and unpublished; the debrief records an instruction to strongly limit sharing it with external AI tools (D11).

3 · The breakthrough

Why switching to RAG changed everything.

Five short beats: the old road, where it led, the pivot, the fixes, and why we can now scale.

3a · How the original setup worked

The default setup searched the whole folder, live, every time.

BOULON came with Copilot Studio's SharePoint connector (a built-in link to a document folder). It ran a keyword search on every question.

3b · Where that road was heading

Every roadblock gets worse as we add manuals.

We have 3,052 manual files to load. On the old road, each one adds more noise.

  1. More files, more wrong matchesPart 1000-1259 returned the wrong file, 1359parts.pdf "Hose, Drain". Another time a filename matched instead of the part.
  2. Exact numbers get lost15 results, 0 exact matches. Part 1000-4270 was reported missing, but it's on the page.
  3. Tables and diagrams are invisibleTorque values live in tables. A snippet search doesn't see the table structure.
  4. No control over cutting or citingThe connector decides how manuals are split and how sources are shown.
  5. Someone types every part by handMy exact lookup was accurate, but only for rows typed in. Impossible for 3,052 files.
  6. No way to measure retrievalWe could only test the whole chatbot. Search problems stayed hidden.

Scaling that way was a dead end: more manuals meant more wrong answers, not better ones.

3c · The pivot

RAG: an open-book exam for BOULON.

RAG (retrieval-augmented generation) means: look up the passage first, then answer only from it.

Hybrid searchexact words + meaning
Semantic rankingbest answer first
Multimodaldiagrams are readable too
Indexan organised, searchable copy
3d · Every roadblock, answered

Because RAG builds its own index, each roadblock has a fix and a proof.

Wrong matches
Meaning-based (semantic) ranking + hybrid searchGolden set: 10/10 with semantic ranking vs 8/10 keyword-only.
Exact numbers lost
The keyword half of hybrid search keeps exact stringsHK98-0021 and 12052641 both found at the top.
Tables and diagrams invisible
Layout extraction + image descriptions (multimodal)Honest: one torque table is still flattened. The fix is part of the rebuild.
No control over cutting or citing
We control the chunking (how manuals are cut) and the fields23 manuals cut into 2,250 passages. The citation label fix comes with the rebuild.
Hand-typing every part
The indexer (the reader program) reads PDFs automaticallyAdding a manual = upload + re-run.
No way to measure
We can test the index directly111 tests on record.
3e · Why it scales now

This is why the project can now move fast.

UploadAdding manuals is an upload and a re-run, not a rebuild.
Re-testThe same test set re-runs after every change.
More = betterBecause RAG ranks by meaning, more manuals mean more coverage, not more confusion.

# Remotion Motion Presentation Handoff

## Production decision
Use Remotion, not PowerPoint. Best template candidates found:
1. `codeverbojan/remotion-cinematic` — cinematic SaaS/product-demo framework with camera movement and editable scenes.
2. `remotion-dev/template-prompt-to-motion-graphics-saas` — official SaaS prompt-to-motion starter.
3. `Thedurancode/locomotion-templates` — many standalone SaaS templates.

## Build target
Create a 1920x1080 MP4, 60-90 seconds, premium dark SaaS-tech motion design.

## Storyboard
1. Title: Maintenance AI Project OS.
2. Current MVP: Copilot Studio + SharePoint manuals.
3. Baseline failures: wrong source, web fallback, wrong part association.
4. Controls applied: web off, ungrounded off, custom search, exact-match filter.
5. Key finding: semantic retrieval is not enough for exact part lookup.
6. Pilot pivot: Valeo Thermo Plus 19-page manual.
7. Sprint roadmap: Sprint 0-4.
8. Stage gates: grounding, retrieval, pilot, reliable lookup, manager demo.
9. Reporting loop: completed, learned, focus, next step.
10. Close: verified answer or unverified status.

## Motion system
Dark navy background, cyan grid lines, mint verified states, amber gates, red/orange risk states. Use spring reveals, line-draw connectors, staggered cards, subtle camera zooms, glow pulses, and morphing system diagrams.

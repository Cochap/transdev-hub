**What Dify is.** Dify is an open-source platform for building LLM (AI language model) apps. It gives you a visual workflow builder, a prompt editor, a knowledge base (documents chunked, embedded and searched, which is RAG), agents with tools, logs of every conversation, and an API so the app can be plugged into other systems. You can run it yourself, or use their cloud. ([Alauda docs](https://docs.alauda.io/ai/2.1/dify/overview/intro.html), [Dify community summary](https://landscape.jimmysong.io/projects/dify/))

**Where it could have helped across concept to production:**
- **Prototyping:** Build and compare chatbot flows and prompts visually, then test models quickly before committing to one.
- **Testing and tuning:** Its conversation logs show which answer came from which passage, which speeds up debugging.
- **Improvement loop:** Change a prompt or workflow step without rebuilding the whole agent.

**Where it would not have solved your problem:**
- **Your 30 GB.** Dify's built-in knowledge base has file caps. Self-hosted, the default is 15 MB per document, and users report uploads still failing above that after raising the limit.
